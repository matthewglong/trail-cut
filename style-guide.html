GRADIENTS // 8 linear · 1 radial

5-stop · full sweep

Each gradient sweeps the full palette in fixed order — granite, coral, pollen, chartreuse, azure. Direction is the only variable. Best deployed sparingly: hero atmospherics, splash artwork, or as a thin colored bar across an interface to suggest the full system at a glance.
